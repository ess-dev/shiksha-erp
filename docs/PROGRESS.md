## Decisions and conventions worth remembering

- Identities hold sign-in data only (no names). Names live in the tenant `staff` table, linked by `identity_ulid`.
- Membership/identity changes are audited in the **platform** audit table (they write landlord data); school-side Actions audit into the school's `audit_events`.
- Existing Data objects are plain `JsonSerializable` classes; new ones use `spatie/laravel-data` 4.23 (installed 2026-10-22, owner-approved) with `spatie/laravel-typescript-transformer` 3.x. Mark each with `#[TypeScript]` and run `composer types:generate` to refresh the committed `resources/js/types/generated.d.ts` (an architecture test fails if it is stale). Composer platform pin is now `8.3.6` (the 3.x transformer's dependency needs >= 8.3.2). Never send models or internal ids to the browser.
- Scope containment is conservative: a campus scope cannot be shown to contain specific sections (no section-to-campus lookup in `Scope::contains`), so only a school-wide scope may hand out section scopes.
- Template changes need a new version in `AccessCatalogSeeder` (never edit an existing version); schools then see "update available".
- Architecture rule allows only these cross-module uses: other modules' `Actions`, `Queries`, `Data`; `Audit`/`Access` `Enums`; the `Identity` model as the acting principal. Students therefore reads sections through `School\Queries\SectionDirectoryQuery` (returns `SectionRefData`, server-side only) and joins tables by name, never School models.
- **Changed decision (2026-10-22, owner):** one phone number is one guardian within a school; the earlier rule "a shared family phone is allowed, warn but don't block" (`.ai/10-tenancy-and-identity.md`, G-rules) no longer applies to students. The guideline text in `.ai/guidelines/` still carries the old wording and needs a PR to match.
- Spatie Data objects can't express string unions in TypeScript (`'a'|'b'` becomes `unknown`): use a PHP backed enum as the property type.
- A permission key must be `area.action` (one dot): `Gate::before` in `AppServiceProvider` only answers keys of that shape.
- The shell here also mangles backslashes in Python heredocs: use the editor tools for any text containing PHP namespaces.

## How to start a new session

1. Read `CLAUDE.md` / `AGENTS.md` (generated from `.ai/guidelines/`), this file, and `docs/DESIGN.md` (the visual and UX style; use it for any screen without a prototype screenshot).
2. `git status` and `git log --oneline -10` to see what changed since "Last updated" above.
3. Make sure PostgreSQL is running and `.env` has the local `shiksha` password; `php artisan migrate && php artisan db:seed` brings a local database up to date.
4. Pick the next step above (or the one the owner names), write a short plan, and begin.
