# Local development environment (Windows, no Docker)

Developers run Windows with **WAMP** (Apache + PHP 8.3), a native **PostgreSQL 18** server, **Node 24 LTS via nvm-windows** and Git for Windows. Servers and CI run Linux. Write code that works on both.

## Environment facts
- Schools are reached at `http://<school>.shiksha.localhost` (Apache vhost `ServerAlias *.shiksha.localhost` → `public/`), or `php artisan serve` on port 8000. No hosts-file entries are needed.
- Local `.env`: `APP_BASE_DOMAIN=shiksha.localhost`, `QUEUE_CONNECTION=database`, `CACHE_STORE=database`, `SESSION_DRIVER=database`. **No Redis locally.** Don't add code that assumes Redis is present outside queue/cache drivers (e.g. raw `Redis::` calls); if Redis-specific behaviour is needed, put it behind the cache/queue abstraction.
- **Horizon, Laravel Pail and anything needing `pcntl`/POSIX signals don't run on Windows.** Locally run `php artisan queue:work`. Don't make local scripts depend on them.
- Commands: use `php artisan …`, `composer …`, `npm run …`. Shell examples in docs or summaries should work in PowerShell or Git Bash; avoid Linux-only tools (`sed -i`, `grep -P`, `xargs`) in project scripts — write them as Artisan commands or Node scripts instead.

## Cross-platform rules
- **File and class names must match exactly in case.** Windows ignores case; Linux doesn't. `RecordPayment.php` must declare `RecordPayment`.
- Build paths with Laravel helpers (`base_path()`, `storage_path()`, `Storage::`) and `/`; never hardcode `\` or drive letters.
- Line endings are LF (`.gitattributes` enforces `* text=auto eol=lf`; developers set `core.autocrlf=false`).
- Don't write to locations outside the project or `storage/`.

## Database
- A local PostgreSQL role with `CREATEDB` stands in for the restricted provisioning role used on servers. Code must still use the configured connection names (`landlord`, `tenant`), never a hardcoded superuser.
- Use the project's reset/seed commands to rebuild landlord + demo schools (`greenfield`, `riverside`). Never point local `.env` at staging or production databases.

## Generated agent files
`CLAUDE.md`, `AGENTS.md`, `.cursor/` rules and `.mcp.json` are generated by Laravel Boost from `.ai/guidelines/`. Edit the files in `.ai/guidelines/`, then run `php artisan boost:update`; never hand-edit the generated output inside the `<laravel-boost-guidelines>` block.
