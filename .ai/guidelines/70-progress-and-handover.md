# Progress and handover

- `docs/PROGRESS.md` is the living record of what is built, the code map, known gaps and the suggested next steps. **Read it at the start of every session and update it in the same commit as the work it describes.**
- Keep it factual: what exists, what was verified (with the commands run), what is still open. Do not record secrets, passwords or personal data in it.
- When a task changes a locked decision or settles an open one, say so in the task summary and reflect it in `docs/PROGRESS.md`.
